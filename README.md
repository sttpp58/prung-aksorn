# รีวิว "ปรุงอักษร" — ห้องทำงานนักแปล / บรรณาธิการนิยาย (v3.0)

## 🚀 เริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: เปิดใช้งานผ่านเบราว์เซอร์ทันที (ไม่ต้องติดตั้ง)
1. ดาวน์โหลดไฟล์ `index.html`
2. ดับเบิลคลิกเปิดไฟล์ด้วย Google Chrome, Microsoft Edge, Safari หรือ Firefox
3. กดปุ่ม **เฟือง (⚙️)** มุมขวาบนเพื่อใส่ **API Key** (OpenAI หรือ Google Gemini)
4. เริ่มสร้างเรื่องนิยายและแปลได้ทันที!

### วิธีที่ 2: ติดตั้งเป็น Progressive Web App (PWA)

* บนสมาร์ตโฟน (iOS/Android): กด **Share** $\rightarrow$ เลือก **"Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)"**

## 1. ฟีเจอร์หลัก: แปลและขัดเกลาสำนวน (Smart Translation Engine)

* **สลับโหมดตามประเภทต้นฉบับ:**
  * **"ภาษาอื่น (แปล)":** แปลนิยายภาษาต่างประเทศ (อังกฤษ, จีน, ญี่ปุ่น ฯลฯ) ออกมาเป็นภาษาไทยที่สละสลวย
  * **"ไทยอยู่แล้ว (ขัดสำนวน)":** พิสูจน์อักษร เรียบเรียง หรือขัดเกลาสำนวนนิยายไทยเดิมให้อ่านลื่นไหลยิ่งขึ้น
* **ปรับแต่งได้ 3 มิติ:** 
  * **ระดับการปรับ:** พิสูจน์อักษร / เรียบเรียง / ขัดเกลาใหม่
  * **แนวเรื่อง (Genre-Aware):** ทั่วไป / แฟนตาซี / โรแมนซ์ / สืบสวน / ไซไฟ / กำลังภายใน
  * **สำนวนภาษา:** ปัจจุบัน / ย้อนยุค / ร่วมสมัย / ทางการ
* 🧠 **ระบบคัดกรองคลังคำอัจฉริยะ (Smart Relevant Glossary Filter):**
  * สแกนเนื้อหาในแต่ละ Chunk ก่อนส่ง และ **ดึงเฉพาะคำศัพท์ที่ปรากฏตัวจริงๆ ในฉากนั้น** เข้าสู่ Prompt (ตรวจจับแบบ Word Boundary สำหรับภาษาอังกฤษ และ Substring สำหรับภาษาไทย)
  * **ประหยัด Token ลง 80–90%** และป้องกันปัญหา AI สมาธิหลุด (Lost in the Middle) ทำให้สำนวนแปลลื่นไหลและใช้ศัพท์เฉพาะได้แม่นยำ 100%
  * แสดง Badge นับจำนวนคำที่ตรวจพบแบบเรียลไทม์บนแถบสถานะ เช่น `กำลังปรุงส่วนที่ 1/4 (ใช้คลังคำ 5 คำ)`
* **แบ่งก้อนข้อความ (Chunking) อัจฉริยะ:** ซอยก้อนข้อความตามย่อหน้า หากย่อหน้าเดียวยาวมากเกินกำหนด ระบบมี `splitOversizedParagraph()` ตัดแบ่งตามเครื่องหมายวรรคตอน (รองรับเครื่องหมายจีน `。！？` ด้วย) การันตีไม่มี Chunk ไหนยาวเกินพิกัด
* **ความต่อเนื่องข้าม Chunk (Contextual Tail):** ส่งท้ายข้อความ 300 ตัวอักษรของ Chunk ก่อนหน้าไปเป็นบริบทช่วยต่อประโยค ทำให้รอยต่อระหว่างส่วนไม่มีการสะดุด
* **ระบบฟื้นฟูงานแปล (Auto-Retry & Resume):**
  * Retry อัตโนมัติเมื่อเจอ Network Error หรือ Rate Limit (429/5xx) สูงสุด 2 ครั้งแบบ Exponential Backoff
  * หากถูกตัดการเชื่อมต่อ มีปุ่ม **"แปลต่อจากที่ค้าง"** ให้ทำต่อจากจุดเดิมได้ทันทีโดยไม่ต้องเริ่มแปลใหม่ตั้งแต่ต้น
* **ควบคุมงานแปลได้สมบูรณ์:** ยุติการทำงานได้ทุกเมื่อผ่าน `AbortController` และสามารถคลิก **"แก้ไขผลลัพธ์"** บนหน้าจอเพื่อพิมพ์แก้คำได้ทันทีก่อนกด **"บันทึกฉบับแก้ไข"**

## 2. ระบบกู้คืน OCR & ถอดรหัสฟอนต์ไดนามิก (Anti-Scraping Decryption)

* **Smart Paste (วางปุ๊บ รู้ใจปั๊บ):** เมื่อคัดลอกข้อความมาวาง ระบบจะทำงานเบื้องหลังทันที:
  1. ล้างอักขระล่องหน (Zero-width spaces, Soft-hyphen `\u00AD`, Word-joiner `\u2060`, BiDi overrides) และแก้สระแอเพี้ยน (`เเ` $\rightarrow$ `แ`)
  2. สแกนหาคำระบุตอนที่บรรทัดแรก (เช่น ตอนที่, Chapter, 第...章, บทนำ) แล้ว **"ดูด"** ไปใส่ช่องชื่อตอนให้อัตโนมัติ พร้อมตัดออกจากเนื้อหาหลักเพื่อไม่ให้ AI แปลซ้ำ
* 🛠️ **ระบบซ่อม OCR 2 ระดับ (`buildOCRRepairPrompt`):**
  * 🇹🇭 **โหมดภาษาไทย (Thai De-obfuscation):** ซ่อมสระลอย, วรรณยุกต์หลุดหาย และใช้ AI ถอดรหัสฟอนต์สุ่มกันก๊อปปี้ (Dynamic PUA Font Obfuscation `\uE000-\uF8FF`) จากบริบทภาษาไทยได้ 100% แม้เว็บนิยายจะสุ่มรหัสฟอนต์ใหม่ทุกตอน (ไม่มีการตัดทอนหรือสรุปความ)
  * 🌐 **โหมดภาษาต่างประเทศ (Foreign Raw Source):** คลีนสแกนดิบภาษาอังกฤษ, ต่อคำที่ถูกตัดข้ามบรรทัดด้วยยัติภังค์ (`trans- lation` $\rightarrow$ `translation`), แก้ตัวอักษรติดกันเพี้ยน (`rn` $\rightarrow$ `m`, `cl` $\rightarrow$ `d`) **โดยมีกฎเหล็กห้ามแอบแปลเป็นภาษาไทย**
* **ระบบตรวจจับข้อความเพี้ยน (`highlightSuspicious`):** สแกนตรวจจับอักขระ PUA, สระลอยที่ไม่มีพยัญชนะนำหน้า (พยัญชนะต้นหาย), สัญลักษณ์ขยะ และตัวอักษรซ้ำ พร้อมแสดงกล่องเตือนสรุปจำนวนบรรทัดและตัวอักษรที่มีปัญหา

## 3. โครงสร้างเรื่อง → เล่ม → ตอน & คลังคำอัจฉริยะ

* **โครงสร้าง 3 ชั้น:** เรื่องนิยาย (`project`) $\rightarrow$ เล่ม (`book`) $\rightarrow$ ตอนที่แปลแล้ว (`history`)
* 📋 **หน้าต่างตรวจสอบคลังคำ (Interactive Glossary Review Modal):**
  * สกัดคลังคำด้วย AI แล้วเปิดเป็น **Pop-up ตาราง Checklist** ให้ตรวจความถูกต้อง
  * ติ๊กเลือก/ไม่เลือกคำศัพท์รายตัว พร้อมปุ่มลัด *เลือกทั้งหมด / ยกเลิกทั้งหมด*
  * **แก้ไขคำแปลภาษาไทยในตารางได้ทันที (Inline Editing)** ก่อนกดยืนยันบันทึก
  * กฎเหล็กบังคับฝั่งซ้ายเป็นภาษาต้นฉบับจริง (`[Source] = [Thai]`) ขจัดปัญหา `คำแปล = คำแปล` และกรองคำที่มีอยู่เดิมในคลังคำให้อัตโนมัติ
* 📚 **สแกนคลังคำจากทุกตอนในเล่ม (Whole-Book Glossary Mining):**
  * กดปุ่มเดียว AI จะอ่านทะลุประวัติทุกตอนในเล่ม โดยใช้เทคนิค **Bilingual Parallel Alignment** ประกบคู่ `[ต้นฉบับ]` กับ `[คำแปลจริง]` 
  * สกัดชื่อตัวละคร สำนัก ระดับพลัง และสมบัติ ออกมาเป็นคลังคำหลักชุดเดียวของทั้งเล่ม
* 🔗 **สืบทอดบริบทและสำนวนข้ามเล่ม (Cross-Book Style & Term Inheritance):**
  * เชื่อมโยงนิยายหลายเล่มจบ (เช่น เล่ม 1 แปลไทยเสร็จแล้ว จะเริ่มแปลเล่ม 2 จากภาษาอังกฤษ)
  * **Persona & Pronoun Bible:** ดึงคู่มือสรรพนาม (เช่น พระเอกแทนตัวว่า "ข้า" เรียกนางเอกว่า "เจ้า") บันทึกใส่ช่อง Context ให้อัตโนมัติ
  * **Bilingual Matching:** จับคู่คำศัพท์ภาษาอังกฤษของเล่มใหม่ให้ตรงกับคำแปลไทยที่เคยใช้ในเล่ม 1
* **ค้นหาในประวัติแบบ Full-Width:** ช่องค้นหาประวัติด้านล่างขยายเต็ม 100% บรรทัดแรก คลีนตา ไม่เบียดกับแถวปุ่มคำสั่ง
* **เทียบความต่างของเวอร์ชัน (LCS Diff):** ปุ่ม `Δ` สำหรับเปิดหน้าต่างเปรียบเทียบฉบับแก้ไขกับฉบับร่างเดิม ไฮไลต์สีเขียว (เพิ่ม) และสีแดง (ลบ) แบบละเอียดระดับคำ
* **ตรวจสอบความสม่ำเสมอ:** ให้ AI สแกนทุกตอนในเล่มเทียบกับคลังคำ เพื่อรายงานจุดที่ชื่อตัวละคร/สถานที่สะกดไม่ตรงกัน

## 4. ประเมินค่าใช้จ่ายและคิวการทำงาน (Token / Cost Meter)

* **Chunk Predictor:** คำนวณแบบเรียลไทม์ใต้กล่องข้อความว่าความยาวปัจจุบันจะถูกส่ง AI กี่ส่วน
* **Live API Cost Tracker:** แถบป้ายราคามุมขวาบน (`$0.0000`) นับยอดค่าใช้จ่ายสะสมจากการใช้งาน Token จริงตามราคาโมเดลล่าสุด (GPT-4o, GPT-4o-mini, GPT-5, Gemini 2.5 Flash, Gemini 3.5 Flash) สามารถคลิกเพื่อรีเซ็ตได้
* **Session Report:** สรุปยอด Token และค่าใช้จ่ายจริงหลังจบการแปล, การซ่อมข้อความ, หรือการสกัดคลังคำ

## 5. โหมดนักอ่านไร้รอยต่อ & อ่านออกเสียง (Reader Mode + TTS)

* **รวมทุกตอนในเล่มเป็นหน้าเดียว:** แสดงผลต่อเนื่องสไตล์หนังสือเล่มจริง พร้อมสารบัญ (TOC Drawer) กดแล้วเลื่อนไปยังตอนนั้นทันที
* **จำขนาดฟอนต์และตำแหน่งอ่านถาวร:** 
  * จดจำขนาดตัวอักษรของโหมดอ่านแยกต่างหากข้ามเซสชัน (`readerFontSize`)
  * จำตำแหน่งเลื่อนหน้าจออ่านล่าสุดแยกตามเล่ม (`readerScrollPos`)
* **Text-to-Speech (Web Speech API):**
  * เล่น / หยุดชั่วคราว / ข้ามย่อหน้า / ปรับความเร็ว 0.6–2.0x / เลือกเสียงอ่านภาษาไทย
  * ไฮไลต์ย่อหน้าที่กำลังอ่านพร้อมเลื่อนหน้าจอตามเสียงอ่านอัตโนมัติ และตัดเสียงทันทีเมื่อปิดหน้าต่าง

## 6. ฐานข้อมูล IndexedDB & การส่งออกผลงาน (Persistence & Export)

* 💾 **Native IndexedDB Storage Engine (`PrungAksornDB`):**
  * ก้าวข้ามขีดจำกัด 5MB ของ localStorage รองรับข้อมูลนิยายหลายร้อยเล่มระดับกิกะไบต์ (GB)
  * **Zero-Loss Auto-Migration:** ย้ายข้อมูลเดิมจาก localStorage เข้าสู่ IndexedDB ให้อัตโนมัติในครั้งแรกที่เปิดใช้งาน
  * **Lifecycle Auto-Flush:** ผูก Event `visibilitychange` บันทึกข้อมูลทันทีเมื่อพับหน้าจอหรือสลับแอปบนมือถือ
* 📥 **Super-Resilient Backup Import:** ระบบกู้คืนข้อมูลสำรองที่รองรับไฟล์ JSON ทุกเวอร์ชัน (ทั้งไฟล์เก่าที่ไม่มี `books[]`, ไฟล์แบบ Array ตรงๆ หรือไฟล์ติด BOM `\uFEFF`) พร้อมคลี่โฟลเดอร์เล่ม 1 ให้เห็นบนหน้าจอทันที
* 📤 **Multi-Format Export:**
  * **Microsoft Word (.docx):** จัดหน้ากระดาษ ฟอนต์ Sarabun และขึ้นหน้าใหม่แยกตามตอนอัตโนมัติ
  * **E-Book (.epub):** ประกอบโครงสร้างตามมาตรฐาน E-Book พร้อมสารบัญดิจิทัล และระบบ **Sanitized XML Metadata** ป้องกันไฟล์เสียหายจากอักขระพิเศษ (`& < > "`)
  * โหลดไลบรารี CDN แบบมีระบบตรวจจับสถานะออฟไลน์ แจ้งเตือนชัดเจนหากไม่มีอินเทอร์เน็ต

## 7. ความปลอดภัยและสถาปัตยกรรม (Security & Architecture)

* **100% Privacy & Zero-Knowledge:** ไม่มีการเก็บข้อมูลลงเซิร์ฟเวอร์ตัวกลาง ผลงานเป็นความลับในเครื่องผู้ใช้ 100%
* **Memory-Only API Key:** คีย์ API ถูกเก็บใน RAM ชั่วคราวขณะเปิดแท็บเท่านั้น ไม่บันทึกลงฐานข้อมูลหรือ Hard Drive
* **Header-Based Authentication:** ส่งคีย์ของ Google Gemini ผ่าน HTTP Header `x-goog-api-key` (ไม่ส่งผ่าน URL Query String ป้องกันประวัติคีย์หลุด)
* **Error Diagnostics & No-Retry on Block:** ดักจับ `promptFeedback.blockReason` และ `finishReason` แปลงเป็นภาษาไทยชัดเจน และตัดการ Retry เปล่าประโยชน์ทันทีเมื่อติดข้อกำหนดความปลอดภัย
* **XSS Hardening:** ข้อความพรีวิว, กล่องเตือน, และ Diff ทำงานผ่าน `escapeHtml()` ป้องกันการรันโค้ดไม่พึงประสงค์ 100%
