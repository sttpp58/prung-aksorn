✒️ รีวิว "ปรุงอักษร" (Prung Aksorn) – ห้องทำงานนักแปลและบรรณาธิการนิยาย AI-Powered ฉบับสมบูรณ์
ปรุงอักษร ไม่ใช่แค่เว็บไซต์สำหรับเรียกใช้ AI API ธรรมดา แต่เป็น "สภาพแวดล้อมการทำงาน (Workspace)" ที่ถูกออกแบบมาอย่างพิถีพิถันเพื่อตอบโจทย์ Pain Point ของนักแปลนิยาย คนทำซับไตเติล และบรรณาธิการต้นฉบับโดยเฉพาะ
แอปนี้ทำงานเป็น Single-Page Application (ไฟล์ HTML เดียว) ที่รันแบบ Local บนเบราว์เซอร์ 100% ปลอดภัย เป็นส่วนตัว และเชื่อมต่อกับ AI ชั้นนำอย่าง OpenAI (GPT-4o) และ Google Gemini ได้โดยตรงผ่านระบบ BYOK (Bring Your Own Key)
🌟 ฟีเจอร์ไฮไลต์ (Core Features)
1. เครื่องมือแปลและขัดเกลาสำนวนขั้นสูง
ปรับจูนมิติภาษาได้ลึก: เลือกโหมดการทำงานได้ทั้ง "แปลภาษาอื่น" หรือ "ขัดสำนวนไทย"
บริบทยืดหยุ่น: ปรับแต่งได้ 3 แกนหลัก คือ ระดับการปรับ (พิสูจน์อักษร/เรียบเรียง/ขัดเกลาใหม่), แนวเรื่อง (แฟนตาซี/สืบสวน/กำลังภายใน ฯลฯ), และ สำนวนภาษา (ปัจจุบัน/ย้อนยุค/ทางการ)
Smart Chunking & Context Bridging: แก้ปัญหา AI ตอบไม่จบด้วยการซอยข้อความยาวๆ เป็นส่วนย่อยอัตโนมัติ (Chunking) โดยไม่ตัดกลางประโยค และที่สำคัญคือ แอบส่งข้อความ 300 ตัวอักษรสุดท้ายของส่วนที่แล้ว ไปเป็นบริบทให้ AI ในส่วนถัดไป ทำให้สำนวนเชื่อมต่อกันแนบสนิทไร้รอยต่อ
2. คลังคำและระบบรักษาความสม่ำเสมอ (Glossary & Consistency)
AI Auto-Extract: กดปุ่มเดียวให้ AI วิ่งอ่านต้นฉบับและดูด "ชื่อตัวละคร/สถานที่" มาสร้างเป็นคลังคำ (Glossary) ให้อัตโนมัติ พร้อมตัดคำซ้ำให้เสร็จสรรพ
Consistency Checker: ฟีเจอร์ระดับ Pro ที่ให้ AI สแกนเนื้อหา "ทั้งเล่ม" เทียบกับคลังคำ เพื่อจับผิดว่ามีตอนไหนแปลชื่อตัวละครเพี้ยนไปจากที่ตกลงไว้หรือไม่
3. โครงสร้างการจัดเก็บระดับโปรดักชัน
แบ่งการจัดเก็บแบบ 3 ลำดับชั้น: เรื่องนิยาย (Project) > เล่ม (Book) > ตอน (Chapter)
รองรับการนำเข้าไฟล์ .txt จำนวนมากพร้อมกัน (Batch Import) และแปลทีละไฟล์ให้อัตโนมัติ
ส่งออกผลงานเป็นไฟล์ Word (.docx) และ E-Book (.epub) ได้ทันทีโดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ (ใช้ไลบรารีผ่านระบบ SRI-pinned CDN)
🔥 ฟีเจอร์ใหม่ล่าสุด (Latest Updates)
🚀 1. Smart Paste & Auto-Title Extraction (วางปุ๊บ รู้ใจปั๊บ)
การ Copy/Paste ต้นฉบับมาวางจะไม่ใช่เรื่องน่าเบื่ออีกต่อไป:
คลีนขยะ OCR อัตโนมัติ: ทันทีที่กด Paste ระบบจะแอบซ่อมแซมอักขระที่ซ่อนอยู่ (PUA Encoding ที่มักทำให้ฟอนต์ไทยพัง) และลบสัญลักษณ์สแกนแปลกๆ ออกให้ในเสี้ยววินาที
ดึงชื่อตอนอัจฉริยะ: ระบบใช้ Regex ขั้นสูงสแกนบรรทัดแรก หากพบคำว่า ตอนที่, บทที่, Chapter, Ep, Prologue, หรือ 第...章 ระบบจะดูดข้อความนั้นไปใส่ในช่อง "ชื่อตอน" ให้อัตโนมัติ และตัดออกจากเนื้อหาหลักเพื่อไม่ให้ AI เอาไปแปลซ้ำซ้อน
💰 2. Token Budget Meter & API Cost Estimator (คุมงบได้ดั่งใจ)
แก้ปัญหาความกังวลเรื่องค่าใช้จ่าย API สานฝันนักแปลสายคุ้มค่า:
Chunk Predictor: ข้างๆ ตัวนับคำ จะบอกล่วงหน้าว่าข้อความยาวๆ นี้จะต้องถูกซอยคิวส่ง AI กี่รอบ
Live Cost Tracking: บน Header มีป้าย $0.00 คอยนับยอดค่าใช้จ่ายสะสมจากการใช้ Token จริง (อิงเรตราคาล่าสุดของ GPT-5o-mini, Gemini 3.1 Pro ฯลฯ)
Session Report: เมื่อแปล หรือซ่อมข้อความเสร็จ จะมีข้อความแจ้งเตือนเล็กๆ บอกว่าแอคชันเมื่อครู่นี้ใช้ Token ไปเท่าไหร่ และคิดเป็นเงินกี่ดอลลาร์
🎧 3. Reader Mode & TTS (โหมดนักอ่านฟังสบาย)
รวบรวมทุกตอนในเล่มมาต่อเป็นหน้าเว็บเดียว พร้อมสารบัญ (TOC) แถบด้านข้าง
Text-to-Speech (TTS): ใช้ Web Speech API อ่านนิยายให้ฟัง สามารถปรับความเร็ว เลือกเสียงอ่าน ไฮไลต์ย่อหน้าที่กำลังอ่าน และข้ามตอนได้เสมือนแอป Audiobook
ระบบจำตำแหน่งที่อ่านค้างไว้ล่าสุด (Scroll tracking)
🛠 สถาปัตยกรรมและความทนทาน (Architecture & Robustness)
Zero-Backend / 100% Local: โค้ดทั้งหมดอยู่ในไฟล์ index.html ไฟล์เดียว ข้อมูลของคุณ (API Key, ต้นฉบับ, คลังคำ) จะอยู่ใน LocalStorage ของเบราว์เซอร์คุณเท่านั้น
Smart Debounce Save: พิมพ์ปุ๊บ เซฟปั๊บ แต่มีการหน่วงเวลา (Debounce) เพื่อไม่ให้เบราว์เซอร์ทำงานหนักเกินไป พร้อมดักจับเหตุการณ์ Storage เต็ม เพื่อเตือนให้ผู้ใช้ Export ข้อมูลล่วงหน้า
AI Auto-Retry: หากเน็ตหลุด หรือ API ติด Limit (429 Too Many Requests) ระบบจะหยุดรอและพยายามยิงคำขอใหม่แบบ Exponential Backoff สูงสุด 2 ครั้ง
Resume Capability: หากแปลยาวๆ แล้วมีปัญหาตรงกลาง สามารถกด "แปลต่อจากที่ค้าง" ได้เลย ไม่ต้องเสียเงินหรือเสียเวลาเริ่มใหม่แต่ต้น
Version Control (Diff): แก้ไขผลลัพธ์จาก AI ได้ และสามารถกดดู Δ (Diff) เพื่อเทียบไฮไลต์คำที่ถูกเพิ่ม/ลด ระหว่างต้นฉบับกับฉบับที่คุณแก้ได้แบบคำต่อคำ
